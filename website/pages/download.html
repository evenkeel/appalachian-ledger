Download and install

Appalachian Bitcoin runs on your own computer and you use it in your web browser. There is no one-click installer yet. Today it takes seven steps and about fifteen minutes, most of it waiting. You will type two commands; they are written out below.

This is beta software. Each release is tested, but it has not had an independent security or accounting review. Keep backups (step 7), and tell us if a step does not go the way this page says.

Download the app (ZIP) Try the demo first

Free, with the source code open to read at GitHub. Nothing to sign up for.

What you need first

  • A Mac with a recent version of macOS, or a PC with Windows 10 or 11.
  • Permission to install software on it, and several gigabytes of free disk space.
  • An internet connection for the installation. After that the app works offline.
  • Docker Desktop, a free program that runs the app in the background. Step 1 installs it.

The app serves one ledger, on the computer you install it on. It is reachable only from that computer.

The steps

  1. Install Docker Desktop

    Go to docker.com/products/docker-desktop and download Docker Desktop. It is free for personal use.

    Mac: choose Apple silicon if your Mac has an M-series chip, or Intel if it is older (Apple menu → About This Mac tells you). Open the downloaded file and drag Docker to Applications.

    Windows: run the installer and keep the option to use WSL 2 ticked. It may ask you to restart.

    Then open Docker Desktop once and wait until it says it is running. You can skip its sign-in and its tutorial. Leave it running.

  2. Download Appalachian Bitcoin

    Download the ZIP file and unzip it (double-click it on a Mac; right-click → Extract All on Windows). You get a folder called appalachian-ledger-main.

    Move that folder somewhere it can stay, such as Documents. Do not rename it later. Your records are tied to the folder’s name.

  3. Open a terminal in that folder

    Mac: open the Terminal app (press ⌘ Space and type Terminal). Type cd and a space, drag the appalachian-ledger-main folder onto the Terminal window, and press Return.

    Windows: open the appalachian-ledger-main folder in File Explorer, right-click an empty part of the window and choose Open in Terminal.

  4. Start the app

    Type these two lines, pressing Return (Enter) after each.

    Mac:

    cp .env.example .env
docker compose up --build -d

    Windows:

    copy .env.example .env
docker compose up --build -d

    The second line downloads what the app needs and builds it. The first time, that takes five to ten minutes and prints a lot of text. It is finished when you get your prompt back and the last lines say Started or Healthy.

  5. Open it and create your account

    In your web browser, go to http://localhost:8080. Choose a username and a password.

    This account exists only on your computer. There is no “forgot my password”, because nobody else has it. Write it down somewhere safe.

  6. Add your first account

    The dashboard opens with a short checklist. Start with the first line: add your checking account and what is in it today. Then add the income you expect and a bill or two. Each line switches on another part of the dashboard, and you can stop after any of them.

  7. Make your first backup

    Go to Settings, find the backup section, type a passphrase and download the backup. Put that file somewhere other than this computer: a USB stick, or another machine.

    Do this now, before you have much to lose, so you know how.

Using it day to day

  • To open it, go to http://localhost:8080. Bookmark it.
  • It starts by itself whenever Docker Desktop is running. If the page does not load, open Docker Desktop and wait a minute.
  • To stop it, open a terminal in the folder (step 3) and type docker compose down. Never add --volumes to that command: it would erase your ledger.
  • To update it, make a backup first. Then download the new ZIP, copy its contents over the old ones in the same appalachian-ledger-main folder (keep your .env file), and run docker compose up --build -d again. Your records carry over.

How backups work

Your whole ledger is one file on your computer. If that computer is lost or its disk fails, a backup is the only other copy.

  • A backup is a single file ending in .albackup, encrypted with the passphrase you type. Without the passphrase it cannot be read, by anyone.
  • There is no recovery. If you lose the passphrase, the backup is useless. Keep the passphrase somewhere separate from the file.
  • Keep more than one, made at different times, and keep them off the computer the app runs on.
  • To restore, open Settings, choose the backup file and enter its passphrase. The app checks the whole file before it replaces anything, and refuses a wrong passphrase or a damaged file without touching your current ledger.
  • The app reminds you when your last backup is getting old.

Other ways to run it

If you are comfortable with a little more setup, the project’s own notes cover running it on a home server so your phone can reach it over your private network, and a single setup command for people who already have Python installed. See browser hosting and backup and restore on GitHub.
