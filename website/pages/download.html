Download

Appalachian Bitcoin is a program for your own computer. Your records stay on that computer. It is free, and the source code is open for anyone to read.

This is beta software. Each release is tested, but it has not had an independent security or accounting review. Keep backups, and tell us if something does not go the way this page says.

Download for Mac Try the demo first

For Macs with Apple silicon (M1 or newer) running macOS 11 (Big Sur) or newer. About 30 MB. Nothing to sign up for. On Windows or an older Intel Mac? See Windows and Intel Macs.

Install it on a Mac

  1. Put it in Applications

    Open the file you downloaded (Appalachian-Bitcoin-mac.dmg). A window opens with the app in it. Drag Appalachian Bitcoin onto the Applications folder, then close that window.

  2. Open it the first time

    Open Appalachian Bitcoin from your Applications folder. Your Mac will say it cannot open it. That is expected: the app is not yet registered with Apple, so the Mac cannot check who made it. Click Done.

    Then open System Settings → Privacy & Security, scroll down to the message about Appalachian Bitcoin, and click Open Anyway. Confirm with your Mac’s password. You only do this once; after that it opens like any other app.

  3. Create your account

    Choose a username and a password. Type the password twice, so a typo cannot lock you out. After this, signing in asks for it once.

    This account exists only on your computer. There is no “forgot my password”, because nobody else has it. Pick one you will remember.

  4. Add your first account

    The dashboard opens with a short checklist. Start with the first line: add your checking account and what is in it today. Then add the income you expect and a bill or two. Each line switches on another part of the dashboard, and you can stop after any of them.

  5. Make your first backup

    Go to Settings, find Backup, type a passphrase and make the backup. It lands in your Downloads folder. Put a copy somewhere other than this computer: a USB stick, or another machine.

    Do this now, before you have much to lose, so you know how.

Using it day to day

  • To open it, click it in Applications or Launchpad. Keep it in the Dock if you like.
  • To close it, quit it like any app (⌘Q). Your records are saved as you go.
  • To update it, make a backup first. Then download the new version and drag it into Applications, replacing the old one. Your records carry over: they are kept apart from the app itself.
  • Live prices need an internet connection. Everything else works offline.

How backups work

Your whole ledger is one file on your computer. If that computer is lost or its disk fails, a backup is the only other copy.

  • A backup is a single file ending in .albackup, locked with the passphrase you type. Without the passphrase it cannot be read, by anyone.
  • There is no recovery. If you lose the passphrase, the backup is useless. Keep the passphrase somewhere separate from the file. A longer passphrase is harder for someone who finds the file to guess.
  • Keep more than one, made at different times, and keep them off the computer the app runs on.
  • To restore, open Settings, choose the backup file and enter its passphrase. The app checks the whole file before it replaces anything, and refuses a wrong passphrase or a damaged file without touching your current ledger.
  • The app reminds you when your last backup is getting old.

Windows and Intel Macs

A Windows app is next. Until then, Appalachian Bitcoin runs on Windows 10 or 11 and on Intel Macs with Docker Desktop, a free program that runs it in the background. You use it in your web browser. It takes about fifteen minutes, most of it waiting, and you type two commands.

  1. Install Docker Desktop

    Download it from docker.com/products/docker-desktop (free for personal use). On Windows, keep the option to use WSL 2 ticked; it may ask you to restart. Open Docker Desktop once and wait until it says it is running. You can skip its sign-in.

  2. Download Appalachian Bitcoin

    Download the ZIP file and unzip it. You get a folder called appalachian-ledger-main. Move it somewhere it can stay, such as Documents, and do not rename it later: your records are tied to the folder’s name.

  3. Start it

    Open a terminal in that folder. On Windows: right-click an empty part of the folder’s window and choose Open in Terminal. On a Mac: open Terminal, type cd and a space, drag the folder onto the window and press Return. Then type these two lines, pressing Enter after each:

    copy .env.example .env
docker compose up --build -d

    On a Mac the first line is cp .env.example .env. The first start takes five to ten minutes. It is done when your prompt comes back and the last lines say Started or Healthy.

  4. Open it

    Go to http://localhost:8080 in your web browser and bookmark it. Then follow steps 3 to 5 above.

It starts by itself whenever Docker Desktop is running. To stop it, type docker compose down in that folder; never add --volumes, which would erase your ledger. To update, make a backup, copy the new ZIP’s contents over the old folder (keep your .env file) and run docker compose up --build -d again.

To reach one ledger from your phone over your home network, see browser hosting on GitHub.
